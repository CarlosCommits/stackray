# Evals

These prompts are optional test cases for the skill-creator workflow. They do not affect normal skill triggering or execution.

Use them only when you want to benchmark or sanity-check the skill against realistic future requests. Each prompt describes a scenario the skill should handle, such as a BuiltWith-vs-Stackray miss, a metadata-only fix, or a JavaScript-heavy detector that needs `httpx -tdh` verification.
